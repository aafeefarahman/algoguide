# AlgoGuide

**Enter a problem and let AlgoGuide identify the best algorithmic approach.**

AlgoGuide is a web app that takes a problem type and its constraints as input and recommends the most suitable algorithmic strategy — Divide & Conquer, Greedy, Dynamic Programming, Backtracking, Branch & Bound, and more — using a classification-based recommender. Built as a resume/portfolio project mapped to a Design and Analysis of Algorithms (DAA) course syllabus, with an eye toward evolving into a standalone SaaS product.

---

## Features

- **Algorithm Recommender** — Enter a problem statement and constraints; get a recommended algorithmic strategy with reasoning.
- **8 Core Taxonomy Categories** — Algorithms are classified into 8 core categories for structured recommendations.
- **Problem Library** — Browse categorized problems and their solving approaches.
- **Quiz / Practice Mode** — Test your understanding of algorithmic strategies.
- **How It Works** — A walkthrough of the recommendation logic.
- **About** — Project background and goals.

---

## Tech Stack

- **Frontend:** React
- **Backend:** FastAPI
- **AI/Recommendation Engine:** Gemini API + classification/decision-tree logic
- **Other:** Python, basic ML for problem-to-category classification
